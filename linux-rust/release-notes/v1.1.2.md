# Kase 1.1.2

**Released:** 2026-11-02 · **Type:** patch release · **Breaking changes:** none

Closing the lid with your AirPods in your ears now plays the 3D lid closing to the end. The README demos now show the live case.

## Fixed

- **The lid closing plays to the end.** If both pods were out (in your ears) when you shut the lid, the 3D case disappeared from the card just as the lid started to close, and the card shrank for a moment before folding away. The card now keeps the case until the lid is shut, then folds 1.5 seconds later. This was found while recording the new README demo. ([#67])

## Documentation

- **The README shows the live case.** The opening demo now shows the island growing into its card as the case turns and opens, each pod lifting out as it's taken, and the lid closing over the hovering pods. The 3D clip goes through a whole open, out, back in and close. "How it works" explains how Kase tells the left pod from the right. ([#67])

## How it was checked

- A new island test covers the lid shutting over worn pods while the card is up, and makes sure closing the lid long after the card has gone still pops nothing.
- All library and island tests pass. The README demos were recorded frame by frame from the real island.

## Upgrading

Open a terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/kase/main/linux-rust/packaging/install.sh | bash
```

Kase restarts in the tray with your settings, saved AirPods and Flatpak overrides intact.

## Known limitations

- Everything listed for [1.1.0](https://github.com/DaBarkle/kase/releases/tag/v1.1.0) still applies.
