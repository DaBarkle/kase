# Kase 1.2.0

**Released:** 2026-11-02 · **Type:** minor release · **Breaking changes:** none

The Kase window now behaves like the Dynamic Island. It has no titlebar, grows out of a small black pill when you open it, changes height to fit each tab, and folds back into the pill when you close it.

## New

- **The window grows out of a pill.** The KDE titlebar and its minimise, maximise and close buttons are gone. Opening Kase shows a black pill the size of the slim island, which grows into the window. The content fades up and settles into place once it's nearly open. The window uses the island's own springs, so the two move alike. ([#69])
- **Closing folds it away.** The × in the top right, Esc, Alt+F4 and closing from the taskbar all fold the window back into the pill before it disappears. Kase keeps running in the tray, as before. ([#69])
- **The window fits each tab.** Its height follows what's on the page. It grows for Island and Settings and shrinks back for AirPods, and it follows the AirPods page as cards come and go. Taller pages scroll, and the window never grows taller than your screen. ([#69])
- **Drag to move.** Drag the empty space around the tabs to move the window. It's KDE's own move, so snapping and Meta+drag work as usual.

## Changed

- Kase draws the window's rounded corners and soft shadow itself. KDE doesn't draw a shadow for a window without a titlebar.
- The width stays at 420. On Wayland an app can't move its own window, and KDE keeps a window's top-left corner in place when it changes size. If the width changed, the window would slide sideways, so only the height changes and the window grows downwards from the top, as the island does.
- The window is resized only when the shape has stopped moving, never on every frame, so the morph doesn't stutter.
- **Reduce motion:** with it on, the window fades in at its full size and closes at once.

## Documentation

- The README's window demos show the window growing out of the pill, fitting each tab and folding away.
- DESIGN.md and JOURNEYS.md describe the window's shape, sizes and motion.

## How it was checked

- New tests cover the window's height rules (the page's height, the minimum and maximum, short screens) and switching springs mid-motion. All 413 library tests and 90 island tests pass.
- The window was recorded frame by frame on the test clock: opening, every tab and closing, in light and dark.
- David tried it on his own KDE Plasma desktop before release.

## Upgrading

Open a terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/DaBarkle/kase/main/linux-rust/packaging/install.sh | bash
```

Kase restarts in the tray with your settings, saved AirPods and Flatpak overrides intact.

## Known limitations

- KDE's own effect for opening windows (System Settings › Window Management › Desktop Effects) still plays as Kase grows. On a see-through window it shows as a quick fade.
- The window can't be resized by dragging its edges. Its size follows its content, like the island's.
- Everything listed for [1.1.0](https://github.com/DaBarkle/kase/releases/tag/v1.1.0) still applies.
